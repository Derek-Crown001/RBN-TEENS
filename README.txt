RBN TEENS REGISTRATION FORM

Files:
- index.html
- style.css
- script.js
- rbn-teens-logo.png

How to use:
1. Keep all four files in the same folder.
2. Open index.html in a browser.
3. The form works as a front-end demo with validation and a success page.
4. IMPORTANT: it does not currently save submissions to a database or send them to email/WhatsApp. Before public launch, connect the submit handler in script.js to a backend/database.

Brand:
- Navy and gold
- Responsive for mobile and desktop
- Uses the supplied RBN logo
- Multi-step form
- Required-field validation
- Parent/Guardian consent
- Community-guideline agreement
- Registration success screen

Recommended next step:
Connect the form to a secure backend such as a Node.js/Express API and database (or a form service) so registrations are actually stored.
